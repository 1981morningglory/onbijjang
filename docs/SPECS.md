# 도구별 스펙

각 도구는 무료 도구 모음 사이트(레퍼런스)의 같은 메뉴를 기준으로 하되, **레퍼런스의 코드·문구·데이터를 가져오지 않고 직접 구현**하고 "업그레이드" 항목을 더한다.
"기본"은 반드시 동작해야 하는 것, "업그레이드"도 이번 범위에 포함이다. 시간이 모자라면 기본을 먼저 완성하고, 못 한 업그레이드는 보고에 명시한다.

공통: 파일 받기는 끌어놓기·선택·Ctrl+V. 여러 결과는 개별 저장 + ZIP. 워터마크는 `WatermarkControls`. 팀 프리셋 반영.

---

## image — 이미지 편집  (`src/tools/image`)

기본
- 여러 장(최대 100장, 한 장 40MB) 목록: 썸네일, 원본 크기·용량, 개별 삭제, 순서 변경.
- 전체 사진 설정(일괄): 크기 맞춤(가로 기준·세로 기준·긴 변 기준·정확한 가로×세로[채우기/여백]·변경 없음), 테두리(두께·색), 좌우 반전, 랜덤 크롭(가로·세로 % 만큼 사진마다 다른 위치로, "다시 섞기"), 밝기·대비·채도, 워터마크(문자/로고, 9방향, 농도, 여백).
- 한 장 정밀 편집(Dialog full): 자르기(자유·1:1·4:3·16:9·3:4·9:16), 회전 90°·임의 각도, 좌우·상하 반전, 텍스트(글꼴·크기·색·외곽선·배경), 화살표·사각형·원·선(색·두께), 모자이크 영역, 되돌리기/다시 실행. 편집 내용은 사진별로 유지되어 다시 열면 수정 가능. `fabric` 사용 가능.
- 저장: JPG·PNG, 품질, 개별 또는 ZIP. 메타정보 제거.

업그레이드
- 저장 형식에 **WebP** 추가.
- **목표 용량 압축**: "한 장 ○○KB 이하"를 주면 품질을 자동 조절(`encodeUnderSize`), 그래도 넘으면 크기를 줄일지 알려준다.
- **마켓 규격 프리셋** 한 번 클릭: 정사각 1000×1000(흰 배경 여백 채우기), 상세페이지 가로 860, 가로 1200 등 + 관리자 "자주 쓰는 크기"(`useTeamPresets().canvasSizes`).
- 결과 미리보기에 저장 전/후 용량 표시.
- `SendToMenu`, `useHandoffFiles('image')`.

## split — 사진 분할  (`src/tools/split`)

기본: 사진 1장. 조각 수 2·4·8·16(세로 우선/가로 우선), 분할선을 끌어서 조절, 균등 분할로 초기화, 분할 전 전체 크기 변경(비율 유지, 2배·3배), PNG/JPG, 조각 번호 미리보기, ZIP 저장.

업그레이드
- **임의 행 × 열**(각 1–20).
- **높이 기준 자르기**: 긴 상세페이지를 "○○px 마다" 자른다(마지막 조각은 남는 만큼). 가로 기준도.
- WebP 저장, 조각 개별 저장, 파일명 규칙(`원본명_01`).
- `useHandoffFiles('split')`, 조각들을 `SendToMenu` 로.

## rename — 파일명 일괄 변경  (`src/tools/rename`)

기본: 파일 여러 개(최대 2,000개·합계 1GB), 공통 이름 + 시작 번호 + 자릿수, 순서 바꾸기(끌기·위/아래), 원본 이름순 정렬, 변경 전/후 미리보기 표, ZIP 저장. 원본은 건드리지 않음.

업그레이드
- 규칙 모드 여러 개: ① 공통 이름+순번 ② **찾아 바꾸기**(일반 문자/정규식, 대소문자) ③ **앞·뒤에 붙이기** ④ **날짜 넣기**(오늘 또는 파일 수정일, YYYYMMDD) ⑤ **엑셀 매핑**: 엑셀에서 복사한 두 열(원래 이름 ↔ 새 이름) 붙여넣기 또는 xlsx 파일. 매칭 안 된 파일 표시.
- 규칙 조합 순서대로 적용, 결과 이름 중복·금지 문자 검사와 경고.
- 초기값은 `useTeamPresets().filename`.
- 변경 내역 CSV 내려받기.
- 순수 함수로 분리하고 단위 테스트.

## qr — QR 코드 생성  (`src/tools/qr`)

기본: URL/텍스트 → QR. 색(전경·배경), 점 모양(사각·둥근·원), 모서리 모양, PNG/JPG/SVG, 크기 512/1024/2048. `qr-code-styling` 사용 가능.

업그레이드
- **가운데 로고 삽입**(오류 복구 수준 자동 상향, 로고 크기·여백).
- 내용 종류: URL, 텍스트, **Wi-Fi**, **연락처(vCard)**, 전화, 문자, 이메일.
- **엑셀 일괄 생성**: 붙여넣은 표(이름, 내용) 또는 xlsx → QR 여러 개 → ZIP(파일명=이름). 최대 500개.
- 팀 브랜드 색, 인쇄 전 "스캔 확인" 안내, 긴 내용일 때 인식률 경고.

## blog — 블로그 본문 정리  (`src/tools/blog`)

기본: 본문 붙여넣기 → 줄바꿈 정리(짧은 줄 정리 on/off, 줄 너비 조절로 미리보기에서 어절 단위 줄바꿈), 중앙정렬 미리보기(폭 고정), 해시태그 키워드 입력(공백·쉼표·# 구분, 정리·중복 제거, 최대 100개), 결과 복사·TXT 저장. 원문은 그대로 보존.

업그레이드
- **글자 수**: 공백 포함/제외, 줄 수, 문단 수, 예상 읽기 시간.
- **키워드 반복 횟수**: 입력한 키워드별 등장 횟수와 본문 내 강조 표시. 너무 많이/적게 쓰인 키워드 표시(기준 직접 설정).
- **금칙어 검사**: 기본 목록(과장·의료·보장 표현 등 일반적인 주의 낱말 20–40개, 직접 작성) + 사용자 목록 추가·저장. 걸린 낱말 위치 강조와 개수.
- 흔한 정리 옵션: 연속 빈 줄 줄이기, 줄 끝 공백 제거, 전각 공백 변환, 이모지 제거.
- 순수 함수 + 단위 테스트.

## background — 배경 제거·바꾸기  (`src/tools/background`)

기본: 사진 → 자동 배경 제거 → 새 배경(투명·단색·그라데이션·내 사진) → 지우기/복원 브러시 수동 보정(크기 조절, 되돌리기) → 경계 부드러움 → PNG/JPG 저장. 원본 비교 보기.

업그레이드
- **여러 장 일괄 처리**(최대 30장, 진행률·취소, ZIP).
- 결과 해상도 제한 완화: 마스크는 모델 해상도로 만들되 **원본 해상도에 맞춰 확대 적용**(가이드 업샘플/부드럽게).
- **흰 배경 정사각 썸네일 자동 생성**: 피사체를 가운데에, 여백 %, 출력 크기(예 1000×1000), 바닥 그림자 옵션.
- 모델: 브라우저에서 돌아가는 **허용 라이선스(MIT/Apache)** 모델을 `@huggingface/transformers` 또는 onnxruntime-web 으로. 후보를 직접 확인해 고른다(예: `onnx-community/BiRefNet_lite`, `Xenova/modnet`, u2net 계열 등 — 실제로 내려받아지는지, 라이선스가 무엇인지 확인). 비상업 전용(예: RMBG-1.4)·AGPL 은 쓰지 않는다. WebGPU 가능하면 사용, 아니면 WASM. 첫 실행 내려받기 크기를 화면에 알린다. 모델을 못 받는 환경을 위해 **단색 배경 지우기(색 기준, 허용 범위 조절)** 방식을 대체 수단으로 함께 제공.
- `useHandoffFiles('background')`, `SendToMenu`.

## cleanup — 작은 표시 지우기  (`src/tools/cleanup`)

기본: 사진 여러 장(최대 30장). 브러시로 지울 곳을 칠하고(크기, 칠한 영역 빼기, 비우기) "칠한 부분 지우기" → 주변 색·무늬로 채움. 원본 비교, 실행 취소/다시 실행, 원본 복원, 확대(100–300%)·이동, PNG/JPG/WebP, ZIP.

업그레이드
- 채움 품질: 단순 흐림이 아니라 **주변 무늬를 이어 붙이는 방식**(예: PatchMatch 류 또는 Telea/Navier-Stokes 류를 직접 구현하거나 허용 라이선스 구현 사용). Web Worker 에서 실행, 진행 표시.
- **사각형·올가미 선택** 추가.
- 화면 안내: "직접 찍었거나 수정 권한이 있는 사진에만 쓰세요. 다른 사람의 저작권·출처 표시를 지우는 데 쓰면 안 됩니다."
- **만들지 않는 것**: 특정 서비스의 워터마크·생성 표식을 자동으로 찾아 지우는 기능은 넣지 않는다.

## mosaic — 사진 모자이크  (`src/tools/mosaic`)

기본: 사진 여러 장(최대 50장). 영역 그리기·이동·8개 손잡이 크기 조절·삭제, 모양(네모/타원), 패턴(픽셀/블러/색 채우기), 강도, 전체 영역, 되돌리기/다시 실행, 확대, **얼굴 자동 감지**(여백 %, 불러올 때 자동 적용 옵션), 워터마크, PNG/JPG/WebP, ZIP. 방향키 이동.

업그레이드
- **글자 영역 자동 감지**: `tesseract.js`(kor+eng)로 글자 상자를 찾아 **전화번호·주민번호 형식·이메일·차량번호·계좌처럼 보이는 숫자열**만 골라 영역 제안(패턴은 정규식, 사용자가 켜고 끌 수 있게). 감지 결과는 제안일 뿐이므로 "직접 확인하세요" 안내.
- 얼굴 감지는 `@mediapipe/tasks-vision` FaceDetector(모델 파일 주소·크기 명시).
- 블러는 되돌릴 수 없도록 충분히 강하게(최소 강도 제한), 안내 문구.
- `useHandoffFiles('mosaic')`, `SendToMenu`.

## template — 템플릿 캔버스  (`src/tools/template`)

가장 큰 도구. `fabric`(v7) 사용 권장.

기본
- 여러 페이지. 페이지 크기 프리셋(검색 가능: 상세페이지 860×3000, 정사각 1080, 카드뉴스 1080×1350, 썸네일 1280×720, 스토리 1080×1920, 배너 1200×400, A4 등) + 직접 입력 + 관리자 "자주 쓰는 크기". 페이지 추가·복제·삭제·순서.
- 객체: 사진(끌어놓기·붙여넣기), 텍스트(글꼴, 크기, 굵게/기울임/밑줄, 정렬, 색, 외곽선, 배경, 그림자, 자간·행간), 도형(사각·둥근 사각·원·삼각·선·화살표, 채우기·테두리·모서리·점선), 손글씨·형광펜.
- 편집: 선택·이동·크기·회전, 복제, 삭제, 그룹/해제, 앞/뒤 순서, 정렬(왼·가운데·오른·위·중간·아래, 페이지 기준), 위치·크기 숫자 입력, 스냅 가이드, 레이어 목록(이름·숨기기·잠금), 사진 보정(밝기·대비·채도), 좌우/상하 반전, 불투명도.
- 되돌리기/다시 실행(Ctrl+Z/Y), 복사/붙여넣기, Delete, 방향키 이동, 확대/화면 맞춤.
- 내보내기: PNG·JPG·WebP·PDF(페이지별 또는 긴 한 장), 페이지별 ZIP, 배율 1×/2×, 투명 배경.
- 애니메이션 내보내기: 페이지를 순서대로 넘기는 **GIF·MP4**(페이지당 시간, 전환 페이드). 객체 등장 효과(서서히·아래에서·팝)는 가능하면.

업그레이드
- **팀 공용 템플릿**: `LibraryMenu kind="canvas-template"` 로 현재 작업(모든 페이지 JSON + 작은 썸네일) 저장·불러오기. 이미지가 포함되므로 저장 용량(20MB)을 넘으면 이미지를 줄여 담고 알린다.
- **작업 자동 저장**: IndexedDB(`idb-keyval`)에 마지막 작업을 저장하고 다시 열면 "이어서 하기".
- **내 PC 글꼴**: `queryLocalFonts()` 지원 브라우저에서 설치 글꼴 불러오기 + 글꼴 파일(.ttf/.otf/.woff2) 추가. 기본 글꼴은 Pretendard, 손글씨는 `@fontsource/nanum-pen-script`, `@fontsource/gaegu`.
- 팀 브랜드 색 빠른 선택(`ColorField`).
- `useHandoffFiles('template')` 로 받은 이미지를 캔버스에 추가.

## clips — 영상 구간 자르기 / gif — 영상 여러 개 변환 / record — 화면 녹화  (`src/tools/clips`, `src/tools/gif`, `src/tools/record`)

세 도구는 인코딩 코드를 공유한다. 공유 코드는 `src/tools/clips/shared/` 에 두고 gif·record 가 가져다 쓴다.

공통 인코딩
- **GIF**: `gifenc`. 팔레트 품질 옵션, FPS 5/10/15/20, 긴 변 320–960px.
- **MP4**: WebCodecs `VideoEncoder` + `mp4-muxer`(H.264). 지원하지 않는 브라우저면 **WebM**(`MediaRecorder` 또는 `webm-muxer`)으로 대체하고 알린다. 소리 포함 옵션은 가능하면(녹화는 MediaRecorder 경로로 가능).
- **WebP 애니메이션**은 선택(구현이 어려우면 보고).
- 출력 틀: 원본 비율 / 16:9 / 9:16 / 1:1, 맞춤(여백 추가[색] / 꽉 채워 자르기), 워터마크(모든 프레임), 진행률·취소, 결과 용량 표시.
- 영상 디코딩은 `<video>` 탐색 + 캔버스(정확한 프레임을 위해 `requestVideoFrameCallback` 사용 가능).

clips 기본: 영상 1개(최대 2GB·60분 — 브라우저가 재생할 수 있는 형식), 타임라인에서 구간 여러 개 지정(재생하며 시작/끝 찍기, 스페이스바, 숫자 직접 입력, 구간 미리 재생), 구간별 이름, 선택 구간 일괄 변환, ZIP.
clips 업그레이드: GIF 는 구간당 최대 60초(용량 경고), **MP4 는 길이 제한 없이**, 긴 변 최대 1080px. `useHandoffFiles('clips')`.

gif 기본: 영상 최대 20개, 영상마다 시작·끝, "모두 처음 N초" 일괄 설정, 순서대로 변환, 개별/ZIP.
gif 업그레이드: 출력 GIF·MP4(용량 줄이기 용도: 해상도·비트레이트 선택). `useHandoffFiles('gif')`.

record 기본: `getDisplayMedia` 로 화면/창/탭 공유 → 미리보기에서 **영역 드래그 지정**(이동·크기·비율 1:1/16:9/4:3, 숫자 입력, 방향키) → 시작 전 카운트다운(0/3/5초) → 녹화 → 결과 미리보기·저장. 워터마크.
record 업그레이드: **MP4(또는 WebM)로 최대 30분 녹화**, GIF 는 최대 60초. 마이크/시스템 소리 포함 옵션(MP4/WebM 일 때). 녹화 중 경과 시간·일시정지. 화면 공유를 지원하지 않는 환경(HTTP 주소, 모바일)에서는 이유와 해결 방법 안내(HTTPS 또는 localhost 에서만 가능).

## pdf — PDF 변환·관리  (`src/tools/pdf`)

탭 구성. 공통: 페이지 썸네일 격자(pdfjs), 페이지 선택·범위 입력(1-3,5), 끌어서 순서 변경, 회전, 삭제, 탭을 옮겨도 추가한 문서 유지.

기본
- **PDF 만들기**: 이미지(JPG·PNG·WebP, 최대 200장) → PDF. 용지(사진 크기 유지 / A4 세로·가로, 여백).
- **PDF → 이미지**: 선택 페이지 PNG/JPG, 해상도(72–300dpi), ZIP.
- **PDF → Word**: 텍스트 추출 docx(`docx`) / 페이지 이미지 docx.
- **PDF → Excel**: 표로 보이는 텍스트를 좌표 기준으로 행·열 추정해 xlsx. 미리보기에서 수정 후 저장.
- **PDF → PPT**: 페이지 이미지 슬라이드(`pptxgenjs`).
- **병합**: 여러 PDF 의 페이지를 골라 합치기. **분할**: 범위별·N쪽마다·한 쪽씩, ZIP.

업그레이드
- **압축**: 페이지를 이미지로 다시 그려 용량 줄이기(품질·dpi 선택, 글자 선택이 안 될 수 있음을 알림) + 가능하면 원본 구조 유지 재저장.
- **페이지 번호 넣기**(위치·시작 번호·형식), **워터마크 글자**(대각선, 농도), **회전 저장**.
- **암호**: `pdf-lib` 는 암호화를 지원하지 않는다. 허용 라이선스의 순수 JS 방법이 있으면 구현하고, 없으면 구현하지 말고 보고(서버 경로로 넣을지 판단은 총괄이 한다). 암호 걸린 PDF 열기는 pdfjs 로 지원(암호 입력).
- **글자 인식(OCR)**: 스캔 PDF·이미지 → `tesseract.js`(kor+eng) → 텍스트/검색 가능한 PDF(보이지 않는 글자 층) 또는 txt·docx. 언어 데이터 내려받기 크기 안내.
- **Word·Excel·PPT·한글 → PDF**:
  - 브라우저 안: docx(`mammoth` → HTML → 인쇄용 화면 → 브라우저 인쇄로 PDF 저장, 또는 캔버스 렌더), xlsx(`xlsx` → 표 → 같은 방식). 서식이 완전히 같지 않음을 알린다.
  - **서버 변환(선택)**: `server/routes/convert.mjs` 를 만들어 서버 컴퓨터에 LibreOffice(`soffice`)가 있으면 `POST /api/convert/office-to-pdf` 로 정확히 변환. `GET /api/convert/status` 로 사용 가능 여부. 업로드는 `multer`(메모리/임시 폴더, 100MB 제한), 변환 후 임시 파일 즉시 삭제, 확장자 화이트리스트(doc, docx, xls, xlsx, ppt, pptx, hwp, hwpx, odt, ods, odp), 명령은 `execFile` 로 인자 배열 전달(셸 사용 금지). 화면에는 "이 기능은 파일을 온비짱 서버로 보냅니다(사내 서버, 변환 후 삭제)"를 분명히 표시하고, 서버 변환이 불가능하면 브라우저 방식만 보여준다. 라우트 파일 형식: `export default function (app, ctx) { … }` — `server/index.mjs` 가 자동으로 불러온다.
- `useHandoffFiles('pdf')`(PDF·이미지), 결과 `SendToMenu`.

## signature — 사진·문서 서명  (`src/tools/signature`)

기본: 사진·PDF·Word(docx) 1개(문서 50쪽 이하). 서명 만들기 3가지 — 이름 입력(글꼴: 기본·명조·손글씨 `nanum-pen-script`·`gaegu`·내 PC 글꼴), 직접 쓰기(마우스·터치·펜, 필압 느낌의 부드러운 선, 한 획 취소), 이미지 올리기(흰 배경 투명하게). 색, 크기, 회전, 불투명도. 페이지 위에서 끌어 배치, 여러 개, 복제, "모든 페이지 같은 위치에". 되돌리기. 저장: PDF(벡터 유지 — 원본 PDF 에 `pdf-lib` 로 서명 이미지 삽입), 이미지 PNG/JPG, Word 는 페이지 이미지로 변환해 저장(docx → 화면 렌더가 어려우면 `mammoth` HTML 렌더를 페이지 이미지로, 한계 안내).

업그레이드
- **서명·직인 보관**: 만든 서명을 이 브라우저(IndexedDB)에 "내 서명"으로 저장해 재사용 + **팀 직인**은 `LibraryMenu kind="signature"`.
- **도장 만들기**: 이름 → 원형/사각 도장(붉은색, 한글 세로 배치) 생성.
- **날짜·텍스트 넣기**(오늘 날짜 한 번에), 체크 표시.
- 안내: "인증서 기반 전자서명이 아닙니다(법적 효력은 용도에 따라 다름)".
- `useHandoffFiles('signature')`.

## capture — 웹페이지 전체 캡처  (`src/tools/capture` + `extension/`)

구성: ① 크롬/엣지 확장 프로그램(Manifest V3) `extension/capture/` ② 사이트의 안내·편집 화면.

확장 프로그램

- 배포: `scripts/build-extension.mjs` 로 `public/downloads/onbijjang-capture.zip` 생성(jszip 사용 가능). 스크립트를 실행해 ZIP 을 만들어 둔다.

사이트 화면
- 설치 안내(다운로드 → 압축 풀기 → `chrome://extensions` 개발자 모드 → 압축해제된 확장 프로그램 로드)를 단계별로. 업데이트 방법.
- 캡처 이미지 받기(확장에서 전달, 파일 끌어놓기, 붙여넣기) → 간단 편집(자르기, 위·아래 잘라내기) → PNG/JPG/PDF 저장, 긴 이미지 **높이 기준 분할**, `SendToMenu`(이미지 편집·모자이크·사진 분할로).

## 마켓 수수료 계산기  (`src/tools/fees/*`)

도구: `compare`(비교), `smartstore`, `coupang`, `rocket`(로켓그로스 마진), `policy`(로켓그로스 정책), `gmarket`, `auction`, `elevenst`. 공유 코드는 `src/tools/fees/shared/`.

요율 데이터 — **가장 중요**
- 각 마켓의 **공식 안내(판매자센터 수수료 안내, 공지)** 를 직접 찾아 `src/tools/fees/shared/rates/*.ts` 에 정리한다. 레퍼런스 사이트나 블로그의 표를 베끼지 않는다. 각 데이터 파일에 `source`(주소), `checkedAt`(확인한 날짜, 오늘은 2026-10-01), `note`(VAT 포함 여부) 를 적는다.
- 공식 자료로 확인하지 못한 값은 **지어내지 않는다.** 그 항목은 "직접 입력"으로 두고 `verified: false` 로 표시해 화면에 "확인 필요" 배지를 보여준다.
- 모든 요율은 화면에서 사용자가 직접 고칠 수 있어야 한다(기본 요율 적용 중/수정됨 표시, 기본값으로 되돌리기).
- 화면 하단에 "요율 기준: ○○ 공식 안내, 2026-10-01 확인 · 실제 정산과 다를 수 있음"을 표시.

각 계산기 기본(레퍼런스와 같은 입력 구조)
- **smartstore**: 배송 방식(유료/무료), 판매가, 원가, 배송비, 사업자 등급(영세·중소1·중소2·중소3·일반 — 네이버페이 주문관리 수수료), 판매 수수료(유입 경로·마케팅 링크 여부에 따른 요율), 쇼핑커넥트 여부·요율. 결과: 예상 이익, 이익률, 총 수수료, 항목별 내역. 각 수수료는 원 미만 버림.
- **coupang**(마켓플레이스): 배송 방식, 상품명(선택), 판매가, 원가, 판매자 부담 배송비, 카테고리 검색·선택(요율 자동), 판매 수수료율, 배송비 수수료율.
- **rocket**: 판매가, 원가, 카테고리(판매 수수료), 사이즈 유형, 입출고·배송비, 쿠팡 창고로 보내는 물류비(총액÷수량), 세이버 가입 여부, 보관일·보관비, 반품·부가서비스 비용(펼치기). 상품 1개 마진.
- **gmarket / auction**: 판매가(할인 전), 판매자 부담 할인, 원가, 카테고리 요율, 배송 방식(무료·선결제·착불)·고객 선결제 배송비·실제 배송비, 제휴채널 이용료, 프로모션 참여 이용료, 월 서버 이용료(전월 판매대금 기준)와 월 예상 판매 건수. 주문 1건 이익과 월 이익을 구분. 두 도구는 같은 컴포넌트에 마켓 설정만 다르게.
- **elevenst**: 판매가, 원가, 카테고리 요율, 배송, 제휴채널 이용료, 쿠폰 적용 후 금액(쿠폰 부담), 월 서버 이용료.
- **policy**: 로켓그로스 공식 정책·요금 페이지 링크 모음(새 창) + **팀 메모**(관리자가 아닌 누구나 볼 수 있는 고정 안내는 코드에, 개인 메모는 localStorage). 공식 링크는 직접 확인한 것만.
- 공통: 예시 불러오기, 입력 초기화, 입력값 유지(`usePersistentState`), 계산 기준 설명(접기), 숫자 입력에 천 단위 표시, 음수 이익은 `text-danger`.

업그레이드
- **역산**: 각 계산기에 "목표 이익률(또는 목표 이익액) → 필요한 판매가" 계산.
- **compare — 마켓 수수료 비교**: 한 상품(판매가·원가·배송 조건·카테고리)을 넣으면 다섯 마켓(스마트스토어·쿠팡·로켓그로스·지마켓·옥션·11번가) 이익·이익률을 한 표로, 가장 남는 곳 표시. 마켓별 세부 옵션은 접어서 조정.
- **엑셀 일괄 계산**(compare 안의 탭): 엑셀에서 복사한 표(상품명, 판매가, 원가, 배송비[, 카테고리]) 붙여넣기 또는 xlsx → 상품별·마켓별 이익표 → xlsx/CSV 저장. 열 매핑 선택.
- **상품 목록 저장**: 자주 계산하는 상품을 이 브라우저에 저장 + `LibraryMenu kind="fee-products"` 로 팀 공유.
- 계산 로직은 순수 함수로 분리하고 **단위 테스트**(원 미만 버림, 무료/유료배송 차이, 역산이 정산과 일치하는지).
