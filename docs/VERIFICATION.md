## 검증 중 찾아 고친 것

1. 마켓 수수료 비교: 쿠팡이 배송비 수수료 하나가 비었다는 이유로 비교에서 통째로 빠짐 → 작은 항목은 0원으로 계산하고 표시, 주요 요율이 빠진 계산은 "참고용"으로 흐리게 표시.
2. 새 버전을 배포하면, 열어 둔 화면에서 도구를 열 때 "도구를 여는 중 문제가 생겼습니다"가 남 → 자동으로 한 번 새로고침, 없는 파일은 404, 첫 화면은 캐시하지 않도록 서버 설정.

## 확인하지 못한 것 (사람이 확인해야 함)

- 화면 녹화의 실제 화면 공유 창(브라우저가 사람의 클릭만 허용).
- 크롬 확장 프로그램 설치와 실제 사이트 캡처.
- 얼굴 자동 찾기(실제 얼굴 사진으로 시험하지 않음).
- 라벨·QR 실제 인쇄와 스캐너 인식, 출력물을 Word·엑셀·PowerPoint·Acrobat 으로 열어 보기.
- 사파리·파이어폭스(크롬 계열에서만 확인).
- 인터넷 주소의 관리자 화면(비밀번호를 아직 정하지 않음).
