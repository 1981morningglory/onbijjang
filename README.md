# 온비짱

팀이 자주 하는 작업을 한곳에 모은 사내 도구 모음입니다. 이미지·영상·문서 도구와 마켓 수수료 계산기, 블로그 글 정리 도구가 들어 있습니다.

사진·영상·문서는 서버로 올라가지 않고 각자의 브라우저 안에서 처리됩니다. 서버는 메뉴 노출 설정, 팀 프리셋, 팀 보관함(템플릿·양식)만 저장합니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

개발(화면 5173, 서버 8787):

```bash
npm run dev
```

팀이 쓰도록 띄우기(화면을 빌드한 뒤 서버 하나로 제공, 기본 포트 8787):

```bash
npm run build
npm start
```

같은 네트워크의 다른 PC에서는 `http://<서버 PC의 IP>:8787` 로 접속합니다. 포트는 환경 변수 `PORT` 로 바꿉니다.

화면 녹화, 클립보드 붙여넣기 버튼, 내 PC 글꼴 불러오기는 브라우저 보안 정책상 **HTTPS 또는 localhost** 에서만 동작합니다. IP 주소로 접속하는 팀원도 쓰려면 사내 인증서로 HTTPS 를 붙이거나 리버스 프록시 뒤에 두세요.

## 인터넷에 배포 (Railway)

GitHub 저장소를 Railway 에 연결하면 `main` 에 올릴 때마다 자동으로 다시 배포됩니다. 빌드·실행 명령은 `railway.json` 에 들어 있습니다.

1. Railway 에서 **New Project → Deploy from GitHub repo** 로 이 저장소를 고릅니다.
2. 서비스에 **Volume** 을 추가하고 마운트 경로를 `/data` 로 합니다. 설정·관리자 비밀번호·팀 보관함이 여기에 저장됩니다. **볼륨이 없으면 다시 배포할 때마다 전부 지워집니다.**
3. **Settings → Networking → Generate Domain** 으로 주소를 만듭니다.
4. 주소가 생기면 바로 `/admin` 에 들어가 관리자 비밀번호를 정합니다(처음 들어온 사람이 정하게 되어 있습니다).

공개된 주소에서는 누구나 도구를 쓸 수 있고, 팀 보관함에 저장하기와 서버 문서 변환은 관리자로 로그인한 사람만 할 수 있습니다. 사내망 전용으로 띄워 팀원 누구나 저장하게 하려면 환경 변수 `TRUSTED_NETWORK=1` 을 줍니다.

| 환경 변수 | 뜻 |
|---|---|
| `PORT` | 서버 포트(Railway 가 자동으로 줍니다) |
| `DATA_DIR` | 데이터 폴더. 지정하지 않으면 Railway 볼륨 경로, 그것도 없으면 `data/` |
| `TRUSTED_NETWORK` | `1` 이면 팀원 누구나 팀 보관함 저장·서버 변환 가능 |
| `ADMIN_PASSWORD` | 있으면 켜질 때 관리자 비밀번호와 전체마스터 계정 `admin` 의 비밀번호를 이 값으로 맞춤(8자 이상, 비밀번호를 잊었을 때) |

## 관리자

`/admin` 에 처음 들어가면 관리자 비밀번호를 정합니다. 이후 관리자는 다음을 바꿀 수 있습니다.

- 신상앱: 메인 화면 맨 위 '(NEW) 신상앱' 칸에 올릴 앱 넣기·빼기·순서, 새로 추가되는 앱 자동 등록(켜고 끄기)
- 메뉴·앱 관리: 도구·그룹을 켜고 끄기, 순서(카테고리를 넘나들어 옮기기 포함), NEW 표시, 등급별(전체마스터·직원등급·일반등급·전체공개) 보이기/감추기, 메뉴에서 삭제·복원, 새 앱(링크) 추가
- 계정·권한: 계정 만들기·등급(전체마스터/직원등급/일반등급)·사용 중지·비밀번호 다시 정하기·삭제, 계정별 도구 허용/차단
- 공지 띠
- 팀 프리셋: 브랜드 색, 팀 워터마크, 자주 쓰는 크기, 파일명 규칙
- 팀 보관함 항목 삭제(저장·불러오기는 누구나)

비밀번호를 잊었으면 서버 PC에서 `data/auth.json` 을 지우고 `/admin` 에서 다시 정합니다.

계정은 `data/users.json` 에, 로그인 서명 키는 `data/session-secret` 에 저장됩니다. 등급은 4단계입니다 — 전체마스터(관리자 화면 사용, 관리자 비밀번호 없이도 들어감) · 직원등급(팀 보관함 저장 가능) · 일반등급(로그인한 일반 사용자) · 전체공개(로그인하지 않은 사람). 계정은 머리말의 [로그인]으로 들어옵니다.

## 견적서·거래명세서 — 팀 공간

견적서 메뉴는 **팀 코드**로 들어갑니다. 다른 팀의 코드를 모르면 그 팀의 문서를 볼 수 없습니다.

1. 관리자 화면 → **팀·회사 자료** 탭에서 팀을 추가하고 처음 팀 코드를 정해 팀에 알려 줍니다. 관리자는 코드 없이 모든 팀에 들어갈 수 있고, 팀이 코드를 잊으면 다시 정해 줄 수 있습니다.
2. 같은 탭에서 **회사 공통 자료** 파일(.json)을 올리면 모든 팀 문서에 상호·직인·사업자등록증·통장 사본이 기본으로 들어갑니다. 팀이 팀 설정에서 따로 저장하면 그 팀은 팀 전용 자료를 씁니다.
3. 팀원은 견적서 메뉴에서 팀 코드를 넣고 들어갑니다(이 브라우저는 180일 기억). 팀 설정에서 팀 코드를 바꾸면 그 팀의 다른 브라우저는 모두 다시 코드를 넣어야 합니다.
4. 팀 공간: **문서 작성**(저장·내려받기하면 문서함에 남음), **문서함**(날짜별, 구분·기간·검색, PDF·엑셀 완성본 내려받기, 열어서 고치기·복사·삭제), **거래처**·**품목**(문서함에서 모아 본 표), **팀 설정**(회사 자료·담당자·팀 코드).

인감·사업자등록증·통장 사본은 공개 저장소인 GitHub 에 넣지 않고 서버 데이터 폴더에만 저장합니다.

## 체험단 SNS 선발

지원자의 인스타그램·네이버 블로그 주소를 붙여 넣으면(또는 설문 결과 엑셀을 끌어다 놓으면) 서버가 천천히 방문해 숫자를 모으고, 각각 상위 150명을 엑셀로 내려받습니다.

- 인스타그램 100 = 팔로워 60 + 최근 게시물 10개 평균 반응(좋아요+댓글) 40. 반응은 Meta 공식 API(Business Discovery)로 읽으며 비즈니스·크리에이터 계정만 나온다. 개인 계정은 공개 프로필에서 팔로워만.
- 블로그 100 = 최근 5일 평균 방문자 70 + 이웃 수 30(네이버는 서로이웃 수를 공개하지 않는다).
- 점수는 지원자 안에서의 위치(백분위) × 가중치. 엑셀 상위 150명 시트 오른쪽에 100점 평가표의 사람 판단 칸(노란색)이 붙는다.
- 인스타그램 API 토큰: 관리자 화면 → ‘SNS 연결’(받는 순서 안내 있음, 60일마다 갱신). 시간당 약 200번 한도라 한 계정에 약 19초.
- 쓸 수 있는 사람: 관리자, 팀 코드로 들어온 사람. 서버에는 SNS 아이디와 숫자만 저장하고, 지원자 이름·연락처는 브라우저에만 둔다.

## 데이터

`data/` 폴더에 저장됩니다. 이 폴더만 백업하면 됩니다.

- `config.json` — 메뉴 노출, 공지, 팀 프리셋
- `auth.json` — 관리자 비밀번호(해시)
- `library/` — 팀 보관함
- `teams.json` — 팀 목록과 팀 코드(해시)
- `teams/<팀>/` — 팀별 문서함(`docs/`), 담당자(`settings.json`), 팀 전용 회사 자료(`kit.json`)
- `company-kit.json` — 회사 공통 자료(인감·사업자등록증·통장 사본)
- `secret.json` — 팀 입장 쿠키 서명 키
- `sns/` — 체험단 선발 작업(`jobs/`), 3일 캐시, 인스타그램 API 토큰(`config.json`)

## 구조

- `src/app` — 뼈대(라우팅, 홈, 사이드바, 관리자, 도구 목록 `registry.ts`)
- `src/ui` — 공통 화면 부품
- `src/lib` — 파일·이미지·워터마크 등 공통 모듈
- `src/tools/<id>` — 도구 하나당 폴더 하나
- `server` — 설정·보관함 서버
- `extension/capture` — 웹페이지 전체 캡처 크롬 확장
- `docs/TOOL_CONTRACT.md` — 도구를 추가·수정할 때의 규약
